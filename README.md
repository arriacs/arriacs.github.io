# arriacs.github.io
## Dataset: https://github.com/Jott2121/ai-career-threat-index
This dataset, AI Career Threat Index, is especially interesting today in understanding the affect of AI on the work force. The dataset "scores 300 US professions on AI displacement risk" (Otterson), using certain statistics to answer questions about AI impact on the particular job and using an equation made of these variable for the final score.
